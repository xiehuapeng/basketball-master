# 项目状态与路线图

## 当前状态

当前阶段：`MVP 工程版`

本阶段目标是把“本地实验脚本”升级成“可以持续迭代的产品项目骨架”，并确认核心视频分析链路是通的。

## 已完成事项

### 代码结构

- 已建立 `src/basketball_analyzer` 包结构
- 已拆分 `analysis`、`rendering`、`detection`、`service` 等模块
- 已保留原实验脚本，方便回溯算法来源

### 交付入口

- 已提供 CLI
- 已提供 FastAPI API
- 已提供标准化 JSON 输出

### 运行验证

- 已跑通单视频分析
- 已跑通球星动作对比
- 已跑通 FastAPI 健康检查
- 已跑通 FastAPI 单视频分析接口
- 已跑通 FastAPI 对比分析接口

### 篮球检测准备

- 已完成远端篮球检测的可插拔接入层
- 已支持 `Roboflow` 和 `Hugging Face`
- 已控制为离手附近少量抽帧，适合 MVP 阶段低成本验证

## 当前框架图

```text
上传视频
  -> API / CLI
  -> AnalysisService
  -> Pose 提取
  -> 动作分析
  -> 可选篮球检测
  -> 视频 / 截图 / JSON 输出
```

## 当前风险

- 离手帧仍然主要依赖启发式规则
- 篮球检测尚未完成真实 Hosted API 联调
- 对比分析已可用，但参考视频定位在部分样本上还不够稳定
